# September 27 usability pass

## What changed

- TV previous/next follows the same selection as the guide: six starting points, a public program block, or search results. It stops at the ends rather than jumping into an unrelated program.
- Program links carry the chosen title, channel, search/block, and guide page. Reload and browser history can restore that state without inventing an account or viewing-history system.
- Selecting a title on a narrow screen returns the viewer to the picture and focuses its heading. Browsing a block does not silently start another program.
- Titles, details links, guide paging, and screen actions have larger touch targets. Copying a program link has a manual fallback if the browser denies clipboard access.
- All twelve example entries in the Unseen concept channel are reachable. The earlier eight-title truncation is removed.
- The six public starting points are an editorial demonstration, not official Creative Control programming. Concept channels and prototype media remain labeled.

## Limits

This pass does not add autoplay, a real schedule, playback progress, an ingest system, permissions, or rights clearance. A tuned title is not a claim that it has been watched. YouTube availability and player restrictions still need checking on the deployed host.
